BS Growth Lab is a modern digital marketing and creative solutions company helping businesses build powerful brands, strengthen online presence, and scale digitally across India and international markets.

## 🌟 Key Features

- **14 Specialized Services**: Full-Funnel Digital Marketing, Reels & Shorts Creation, Social Media Management, Google & Meta Ads, SEO, Branding, Web Development, and more.
- **Strategic Solutions Diagnosis**: Problem-to-outcome mapping addressing organic reach plateaus, low ad ROAS, and fragmented online presence.
- **Dual Currency Architecture**: Seamless on-the-fly currency toggle supporting both **INR (₹)** and **USD ($)**.
- **Company Leadership**: Highlighted executive leadership by Founder & Owner **Sayyed Bilal**.
- **Interactive Portfolio**: Filterable project showcase with category filters and interactive modal previews.
- **Conversion & Lead Engines**:
  - Direct WhatsApp click-to-chat pre-populated enquiry integration.
  - Interactive on-page and modal enquiry forms with celebratory confetti animations.
- **Full Administrative Management Portal**:
  - Secure credential authentication.
  - Real-time enquiry CRM with status lifecycle management, search, and CSV export.
  - Dynamic portfolio project and pricing package manager.
  - Built-in Supabase synchronization toggle with offline LocalStorage fallback and copyable SQL schema.
- **Automated CI/CD**: Ready-to-go GitHub Actions workflow (`.github/workflows/deploy.yml`) for instant GitHub Pages deployment.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub.
2. In your repository on GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The included `.github/workflows/deploy.yml` workflow will automatically trigger on push to `main` and deploy your site live!
